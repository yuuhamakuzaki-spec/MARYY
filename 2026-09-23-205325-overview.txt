
> Overview
  Before a customer ever sees an e-commerce storefront, the backend operations
  and administration interface must be fully operational, secure, and
  accessible.

  For this phase of your prototype, your team’s primary focus is building and
  designing the Admin Panel / Dashboard. You will demonstrate how store
  managers handle catalog management, order processing, and system
  administration before connecting these to the customer-facing frontend.


  Core Deliverables & Specifications
  1. Admin Dashboard & Operations (Primary Focus)
  Your admin prototype must demonstrate functional or simulated UI flows for
  the following:

  Catalog & Inventory Management Panel:


  Interface to add, edit, and delete products.

  Fields for SKU setup, pricing, stock levels, variants (e.g., sizes, colors),
  and product categories.

  Automated low-stock alerts or safety stock warning indicators.

  Order Lifecycle Management Panel:


  View incoming customer orders and track order status (e.g., Pending,
  Processing, Shipped, Delivered, Refunded).

  Interface to simulate generating shipping labels, assigning tracking numbers,
  or processing returns/refunds.

  Inclusive Form & Data Entry Design:


  Ensure admin data-entry forms support flexible customer profile inputs (e.g.,
  single "Full Name" field support, inclusive gender choices, and non-binary
  title fields).

  2. Technical & Security Controls (Admin Level)
  Role-Based Access & Authentication:


  Design/simulate a secure login page enforcing Multi-Factor Authentication
  (MFA) prompts for store administrators

  Infrastructure Specification:


  Specify your underlying stack type (SaaS like Shopify, Open-Source like
  WooCommerce, or Custom/Headless like React/Next.js + Node).

  Briefly document how your backend stores transactional data securely (e.g.,
  database selection, encryption standards like AES-256 or bcrypt for
  passwords).

  3. Inclusive UI/UX & Web Accessibility (WCAG in Admin Panel)
  Even internal admin tools must be accessible! Apply the POUR framework to
  your admin dashboard:

  Perceivable: All uploaded media thumbnails in the catalog manager must accept
  descriptive alt text. Ensure high color contrast (WCAG AA standard) for
  status badges (e.g., "Out of Stock" or "Payment Failed" must use explicit
  text, not just red/green colors).

  Operable: Admin tables, dropdowns, and form inputs must be fully accessible
  via keyboard (Tab, Enter, arrow keys) with clear focus indicators.

  Understandable: Provide clear error validation on admin forms (e.g., "SKU
  must be unique" or "Price must be a positive number").

  Robust: Use proper semantic HTML structure (<main>, <nav>, <table, <button>).

  Submission Requirements
  Submit the following to the LMS:

  Admin Prototype Link: Interactive link to your admin panel (Figma prototype,
  hosted live web app, or repository).

  Technical & Accessibility Documentation (PDF - 2 Pages):

  WCAG Admin Audit: Highlight 3 specific accessibility choices integrated into
  your admin interface.

  Admin Walkthrough Video (3–5 minutes):

  A recording demonstrating an administrator logging in, adding a new product
  variant, managing stock levels, changing an order status, and navigating the
  admin dashboard using keyboard-only controls.
